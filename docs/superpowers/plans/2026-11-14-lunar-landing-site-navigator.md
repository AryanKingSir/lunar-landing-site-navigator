# Lunar Landing Site Navigator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a web app that compares lunar landing sites and dates. It shows Sun and Earth positions against the real LOLA terrain horizon, and reports solar-power and DSN-aware direct-to-Earth (DTE) windows.

**Architecture:**
- A Python FastAPI backend computes topocentric Sun/Earth az/el with Skyfield and NAIF lunar kernels (libration included).
- It computes horizon masks by ray-marching LOLA south-pole elevation data, then derives visibility, power and DSN metrics.
- A React + Vite + TypeScript frontend (zustand state) renders comparison metrics, a 360° horizon panorama, a Gantt timeline and a three.js terrain view, all synced to one mission-elapsed-time scrubber.

**Tech Stack:**
- Backend: Python 3.12+, FastAPI, Skyfield, numpy, Pillow, certifi, pytest.
- Frontend: Node 20+, React 19, Vite 6, TypeScript 5.8, zustand 5, three + @react-three/fiber 9 + drei 10, vitest 3.

Spec: `docs/superpowers/specs/2026-11-14-lunar-landing-site-navigator-design.md`

## Global Constraints

- Lunar reference sphere radius: **R = 1737.4 km** (`1737400.0` m) everywhere (DEM, horizon, projection).
- DEM: LOLA `ldem_80s_80m.img`, little-endian int16, 7600×7600, height_m = DN × 0.5, scale 80 m/px, projection centre at 0-based pixel 3799.5, polar stereographic, south pole.
- Projection (from PDS `DSMAP_POLAR.CAT` inverse equations, south pole):
  - `r = 2R·tan((90+lat)°/2)`, `x = r·sin(lon)`, `y = r·cos(lon)`
  - `col = x/scale + offset`, `row = −y/scale + offset`
  - Lon 0 points up the image; 90°E points right.
- Azimuth: degrees clockwise from local north (toward east), 0–360. Elevation in degrees. No refraction.
- Horizon masks: 720 azimuth bins (0.5°), observer height 2.0 m default, max range 150 km.
- Sun radius 695,700 km; Earth radius 6,371 km. Earth counts as "visible" when ≥ 50 % of its disk is above the mask. The Sun is "up" when any part of its disk is above the mask (`sun_frac > 0`).
- DTE requires Earth visible AND at least one DSN complex (Goldstone, Madrid, Canberra) seeing the Moon at ≥ 10° elevation.
- Power: `P = 1361·(1 AU / r)²·frac·max(cos i, 0)·area·eff`. Defaults: vertical sun-tracking panel, 1 m², 30 %.
- Timestamps cross the API as UTC epoch milliseconds (ints). Request datetimes are ISO-8601 UTC.
- Max 5,000 samples per scenario request (memory cap for 512 MB hosting).
- Max 4 scenarios in the UI.
- UI: dark mission-control theme. Sun = amber `#f5a524`, Earth = blue `#4cc9f0`, DTE = green `#80ed99`.
- Commit on `main` after every task (user-approved workflow).
- Raw downloads live in `backend/data/raw/` (gitignored). Generated small products (`dem_240m.npz`, `horizons/*.json`, `frontend/public/terrain/*`) are committed.

```python
"""Download SPICE kernels and the LOLA south-pole DEM into backend/data/raw.

Usage: python scripts/download_data.py [--kernels] [--dem]   (no flag = both)
"""
import argparse
import shutil
import ssl
import sys
import urllib.request
from pathlib import Path

import certifi

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from app.config import DEM_DOWNLOAD, KERNELS, RAW_DIR  # noqa: E402


def fetch(name: str, url: str, size: int | None) -> None:
    dest = RAW_DIR / name
    if dest.exists() and (size is None or dest.stat().st_size == size):
        print(f"skip {name} (present)")
        return
    RAW_DIR.mkdir(parents=True, exist_ok=True)
    tmp = dest.with_name(dest.name + ".part")
    ctx = ssl.create_default_context(cafile=certifi.where())
    print(f"downloading {name} ...", flush=True)
    with urllib.request.urlopen(url, context=ctx, timeout=60) as resp, open(tmp, "wb") as out:
        shutil.copyfileobj(resp, out, 1 << 20)
    got = tmp.stat().st_size
    if size is not None and got != size:
        tmp.unlink()
        raise SystemExit(f"{name}: expected {size} bytes, got {got}")
    tmp.rename(dest)
    print(f"ok {name} ({got} bytes)")


def main() -> None:
    p = argparse.ArgumentParser()
    p.add_argument("--kernels", action="store_true")
    p.add_argument("--dem", action="store_true")
    a = p.parse_args()
    both = not (a.kernels or a.dem)
    if a.kernels or both:
        for name, (url, size) in KERNELS.items():
            fetch(name, url, size)
    if a.dem or both:
        for name, (url, size) in DEM_DOWNLOAD.items():
            fetch(name, url, size)


if __name__ == "__main__":
    main()
```

```python
"""Fetch reference Sun/Earth az/el from the JPL Horizons API for ephemeris tests."""
import json
import ssl
import urllib.parse
import urllib.request
from datetime import datetime
from pathlib import Path

import certifi

OUT = Path(__file__).resolve().parent.parent / "tests" / "fixtures" / "horizons.json"
SITES = {
    "connecting-ridge": (-89.4667, -136.667, 1947.0),
    "apollo11": (0.67408, 23.47297, 0.0),
}
TIMES = ["2026-11-20 00:00", "2026-12-05 12:00", "2027-01-10 06:30"]
BODIES = {"sun": "10", "earth": "399"}
API = "https://ssd.jpl.nasa.gov/api/horizons.api"


def query(body: str, lat: float, lon: float, elev_m: float) -> list[tuple[str, float, float]]:
    params = {
        "format": "json",
        "COMMAND": f"'{body}'",
        "CENTER": "'coord@301'",
        "COORD_TYPE": "'GEODETIC'",
        "SITE_COORD": f"'{lon},{lat},{elev_m / 1000.0}'",
        "MAKE_EPHEM": "'YES'",
        "EPHEM_TYPE": "'OBSERVER'",
        "TLIST": " ".join(f"'{t}'" for t in TIMES),
        "TLIST_TYPE": "'CAL'",
        "QUANTITIES": "'4'",
        "ANG_FORMAT": "'DEG'",
        "CSV_FORMAT": "'YES'",
        "EXTRA_PREC": "'YES'",
    }
    url = API + "?" + urllib.parse.urlencode(params)
    ctx = ssl.create_default_context(cafile=certifi.where())
    with urllib.request.urlopen(url, context=ctx, timeout=60) as r:
        result = json.load(r)["result"]
    block = result.split("$$SOE")[1].split("$$EOE")[0]
    rows = []
    for line in block.strip().splitlines():
        parts = [p.strip() for p in line.split(",")]
        stamp = datetime.strptime(parts[0], "%Y-%b-%d %H:%M:%S.%f")
        rows.append((stamp.strftime("%Y-%m-%dT%H:%M:%SZ"), float(parts[3]), float(parts[4])))
    return rows


def main() -> None:
    out = []
    for site, (lat, lon, elev) in SITES.items():
        for body_name, body in BODIES.items():
            for time_utc, az, el in query(body, lat, lon, elev):
                out.append({"site": site, "lat": lat, "lon": lon, "elev_m": elev,
                            "body": body_name, "time_utc": time_utc, "az": az, "el": el})
    OUT.parent.mkdir(parents=True, exist_ok=True)
    OUT.write_text(json.dumps(out, indent=1))
    print(f"wrote {len(out)} rows to {OUT}")


if __name__ == "__main__":
    main()
```

```python
"""Topocentric Sun and Earth positions for an observer on the lunar surface.

Uses Skyfield's documented Moon-frame recipe (MOON_ME_DE421 via moon_080317.tf +
moon_pa_de421 binary PCK), which includes physical libration.
"""
from dataclasses import dataclass
from functools import lru_cache

import numpy as np
from skyfield.api import Loader
from skyfield.planetarylib import PlanetaryConstants

from app.config import RAW_DIR


@dataclass(frozen=True, eq=False)
class Ephem:
    sun_az: np.ndarray
    sun_el: np.ndarray
    sun_dist_km: np.ndarray
    sun_vec: np.ndarray
    earth_az: np.ndarray
    earth_el: np.ndarray
    earth_dist_km: np.ndarray
    earth_vec: np.ndarray


@lru_cache(maxsize=1)
def kernels():
    load = Loader(str(RAW_DIR), verbose=False)
    ts = load.timescale(builtin=True)
    eph = load("de440s.bsp")
    pc = PlanetaryConstants()
    pc.read_text(load("moon_080317.tf"))
    pc.read_text(load("pck00011.tpc"))
    pc.read_binary(load("moon_pa_de421_1900-2050.bpc"))
    frame = pc.build_frame_named("MOON_ME_DE421")
    return ts, eph, pc, frame


def times_from_ms(t_ms: np.ndarray):
    ts = kernels()[0]
    return ts.utc(1970, 1, 1, 0, 0, np.asarray(t_ms, dtype=float) / 1000.0)


def _observe(site, target, t, frame):
    app = site.at(t).observe(target).apparent()
    alt, az, dist = app.altaz()
    xyz = np.asarray(app.frame_xyz(frame).au, dtype=float).T.reshape(-1, 3)
    vec = xyz / np.linalg.norm(xyz, axis=1, keepdims=True)
    return (np.atleast_1d(az.degrees), np.atleast_1d(alt.degrees),
            np.atleast_1d(dist.km), vec)


def body_altaz(lat_deg: float, lon_deg: float, elev_m: float, t_ms: np.ndarray) -> Ephem:
    _, eph, pc, frame = kernels()
    site = eph["moon"] + pc.build_latlon_degrees(frame, lat_deg, lon_deg, elevation_m=elev_m)
    t = times_from_ms(t_ms)
    s_az, s_el, s_d, s_v = _observe(site, eph["sun"], t, frame)
    e_az, e_el, e_d, e_v = _observe(site, eph["earth"], t, frame)
    return Ephem(s_az, s_el, s_d, s_v, e_az, e_el, e_d, e_v)
```

```python
"""LOLA polar-stereographic DEM access and terrain horizon masks (south pole).

Projection follows PDS DSMAP_POLAR.CAT (south pole): lon 0 up, 90E right.
Heights are metres relative to the 1737.4 km reference sphere.
"""
from dataclasses import dataclass
from pathlib import Path

import numpy as np

R_MOON_M = 1737400.0
N_AZ = 720
MAX_RANGE_M = 150_000.0
FULL_COVERAGE_LAT = -84.9  # south of this, 150 km rays stay inside the 80S DEM disk


@dataclass(frozen=True, eq=False)
class Dem:
    heights: np.ndarray  # (n, n) float32 metres
    scale_m: float       # metres per pixel
    offset: float        # 0-based pixel coordinate of the pole

    @property
    def n(self) -> int:
        return self.heights.shape[0]


def latlon_to_xy(lat, lon):
    r = 2.0 * R_MOON_M * np.tan(np.radians(90.0 + np.asarray(lat, float)) / 2.0)
    lam = np.radians(np.asarray(lon, float))
    return r * np.sin(lam), r * np.cos(lam)


def xy_to_latlon(x, y):
    r = np.hypot(x, y)
    lat = -90.0 + np.degrees(2.0 * np.arctan(0.5 * r / R_MOON_M))
    lon = np.degrees(np.arctan2(x, y))
    return lat, lon


def _xy_to_pixel(dem: Dem, x, y):
    return np.asarray(x) / dem.scale_m + dem.offset, -np.asarray(y) / dem.scale_m + dem.offset


def sample(dem: Dem, x, y) -> np.ndarray:
    col, row = _xy_to_pixel(dem, x, y)
    c0 = np.floor(col).astype(np.int64)
    r0 = np.floor(row).astype(np.int64)
    valid = (c0 >= 0) & (r0 >= 0) & (c0 < dem.n - 1) & (r0 < dem.n - 1)
    c0c = np.clip(c0, 0, dem.n - 2)
    r0c = np.clip(r0, 0, dem.n - 2)
    fc = col - c0c
    fr = row - r0c
    h = dem.heights
    v = (h[r0c, c0c] * (1 - fc) * (1 - fr) + h[r0c, c0c + 1] * fc * (1 - fr)
         + h[r0c + 1, c0c] * (1 - fc) * fr + h[r0c + 1, c0c + 1] * fc * fr)
    return np.where(valid, v, np.nan)


def height_at(dem: Dem, lat: float, lon: float) -> float:
    x, y = latlon_to_xy(lat, lon)
    return float(sample(dem, np.array([x]), np.array([y]))[0])


def horizon_dip_deg(obs_h: float) -> float:
    return float(np.degrees(np.arccos(R_MOON_M / (R_MOON_M + obs_h))))


def smooth_horizon(obs_h: float, n_az: int = N_AZ) -> np.ndarray:
    return np.full(n_az, -horizon_dip_deg(obs_h))


def horizon_mask(dem: Dem, lat: float, lon: float, obs_h: float = 2.0,
                 n_az: int = N_AZ, max_range_m: float = MAX_RANGE_M) -> np.ndarray:
    """Max terrain elevation angle (deg) per azimuth bin, including lunar curvature."""
    x0, y0 = latlon_to_xy(lat, lon)
    h0 = float(sample(dem, np.array([x0]), np.array([y0]))[0])
    if np.isnan(h0):
        raise ValueError(f"site {lat},{lon} is outside the DEM")
    colat = np.radians(90.0 + lat)
    k = 2.0 / (1.0 + np.cos(colat))  # stereographic scale factor (projected / ground)
    az = np.radians(np.arange(n_az) * 360.0 / n_az)
    ang = np.radians(lon) + az       # direction in projected plane: (sin, cos)
    d = np.arange(1, int(max_range_m / dem.scale_m) + 1) * dem.scale_m  # ground metres
    X = x0 + np.sin(ang)[:, None] * d[None, :] * k
    Y = y0 + np.cos(ang)[:, None] * d[None, :] * k
    H = sample(dem, X, Y)
    theta = d / R_MOON_M
    r_obs = R_MOON_M + h0 + obs_h
    r_t = R_MOON_M + H
    el = np.degrees(np.arctan2(r_t * np.cos(theta) - r_obs, r_t * np.sin(theta)))
    el = np.where(np.isnan(el), -np.inf, el)
    mask = el.max(axis=1)
    return np.maximum(mask, -horizon_dip_deg(obs_h)) if np.isinf(mask).any() else mask


def load_dem_img(path: Path, n: int = 7600, scale_m: float = 80.0) -> Dem:
    dn = np.fromfile(path, dtype="<i2").reshape(n, n)
    return Dem(dn.astype(np.float32) * 0.5, scale_m, n / 2 - 0.5)


def load_dem_npz(path: Path) -> Dem:
    d = np.load(path)
    return Dem(d["dn"].astype(np.float32) * 0.5, float(d["scale_m"]), float(d["offset"]))
```

```python
"""Build terrain products from LOLA LDEM_80S_80M (run after download_data.py --dem).

Outputs:
  data/dem_240m.npz                     runtime DEM for on-demand custom-site horizons
  data/horizons/<site-id>.json          80 m horizon masks for curated south-pole sites
  frontend/public/terrain/heightmap.bin uint16 500x500 over a 360 km box (3D view)
  frontend/public/terrain/hillshade.png 900x900 shaded relief (site-picker map)
  frontend/public/terrain/meta.json
"""
import json
import sys
from pathlib import Path

import numpy as np
from PIL import Image

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from app import terrain  # noqa: E402
from app.config import DEM_RAW, DEM_RUNTIME, FRONTEND_TERRAIN_DIR, HORIZONS_DIR  # noqa: E402
from app.sites import load_sites  # noqa: E402

CROP = slice(1550, 6050)  # 4500 px x 80 m = 360 km box centred on the pole (centre 3799.5)


def build_runtime_dem(dem80: terrain.Dem) -> None:
    h = dem80.heights[:7599, :7599].reshape(2533, 3, 2533, 3).mean(axis=(1, 3))
    dn = np.round(h / 0.5).astype(np.int16)
    np.savez_compressed(DEM_RUNTIME, dn=dn, scale_m=240.0, offset=(dem80.offset - 1.0) / 3.0)
    print(f"wrote {DEM_RUNTIME} ({DEM_RUNTIME.stat().st_size / 1e6:.1f} MB)")


def build_curated_horizons(dem80: terrain.Dem) -> None:
    HORIZONS_DIR.mkdir(parents=True, exist_ok=True)
    for s in load_sites():
        if s["lat"] > -80:
            continue
        mask = terrain.horizon_mask(dem80, s["lat"], s["lon"], obs_h=2.0)
        out = {"id": s["id"], "az_step": 0.5, "el": np.round(mask, 3).tolist(),
               "site_height_m": round(terrain.height_at(dem80, s["lat"], s["lon"]), 1),
               "partial": s["lat"] > terrain.FULL_COVERAGE_LAT}
        (HORIZONS_DIR / f"{s['id']}.json").write_text(json.dumps(out))
        print(f"{s['id']}: h0={out['site_height_m']} m, mask max {mask.max():.2f} deg")


def _hillshade(h: np.ndarray, cell_m: float, az_deg: float = 315.0, alt_deg: float = 45.0) -> np.ndarray:
    gy, gx = np.gradient(h, cell_m)
    slope = np.pi / 2 - np.arctan(np.hypot(gx, gy))
    aspect = np.arctan2(-gx, gy)
    az = np.radians(360.0 - az_deg + 90.0)
    alt = np.radians(alt_deg)
    shaded = np.sin(alt) * np.sin(slope) + np.cos(alt) * np.cos(slope) * np.cos(az - aspect)
    return (np.clip(shaded, 0, 1) * 255).astype(np.uint8)


def build_frontend_terrain(dem80: terrain.Dem) -> None:
    FRONTEND_TERRAIN_DIR.mkdir(parents=True, exist_ok=True)
    crop = dem80.heights[CROP, CROP]
    hm = crop.reshape(500, 9, 500, 9).mean(axis=(1, 3))
    lo, hi = float(hm.min()), float(hm.max())
    ((hm - lo) / (hi - lo) * 65535).round().astype("<u2").tofile(FRONTEND_TERRAIN_DIR / "heightmap.bin")
    hs = crop.reshape(900, 5, 900, 5).mean(axis=(1, 3))
    Image.fromarray(_hillshade(hs, 400.0)).save(FRONTEND_TERRAIN_DIR / "hillshade.png")
    meta = {"extent_m": 360000, "heightmap_n": 500, "h_min_m": round(lo, 1),
            "h_max_m": round(hi, 1), "hillshade_n": 900}
    (FRONTEND_TERRAIN_DIR / "meta.json").write_text(json.dumps(meta))
    print(f"frontend terrain: {meta}")


def main() -> None:
    dem80 = terrain.load_dem_img(DEM_RAW)
    build_runtime_dem(dem80)
    build_curated_horizons(dem80)
    build_frontend_terrain(dem80)


if __name__ == "__main__":
    main()
```

```python
"""Disk visibility above a terrain mask and boolean-series -> time windows."""
import numpy as np

SUN_RADIUS_KM = 695_700.0
EARTH_RADIUS_KM = 6_371.0


def angular_radius_deg(radius_km, dist_km):
    return np.degrees(np.arcsin(radius_km / np.asarray(dist_km, dtype=float)))


def disk_fraction(center_el, radius_deg, horizon_el):
    """Fraction of a circular disk above a horizontal line (circular-segment area)."""
    h = (np.asarray(center_el, float) - np.asarray(horizon_el, float)) / np.asarray(radius_deg, float)
    h = np.clip(h, -1.0, 1.0)
    return 1.0 - (np.arccos(h) - h * np.sqrt(1.0 - h * h)) / np.pi


def interp_mask(mask_el: np.ndarray, az_deg) -> np.ndarray:
    n = len(mask_el)
    pos = np.mod(np.asarray(az_deg, float), 360.0) / (360.0 / n)
    i0 = np.floor(pos).astype(np.int64) % n
    i1 = (i0 + 1) % n
    f = pos - np.floor(pos)
    return mask_el[i0] * (1 - f) + mask_el[i1] * f


def _runs(flag) -> tuple[np.ndarray, np.ndarray]:
    padded = np.concatenate([[0], np.asarray(flag, bool).astype(np.int8), [0]])
    d = np.diff(padded)
    return np.where(d == 1)[0], np.where(d == -1)[0]


def to_windows(t_ms, flag, step_ms: int) -> list[list[int]]:
    starts, ends = _runs(flag)
    return [[int(t_ms[s]), int(t_ms[e - 1]) + int(step_ms)] for s, e in zip(starts, ends)]


def longest_run(flag) -> int:
    starts, ends = _runs(flag)
    return int((ends - starts).max()) if len(starts) else 0
```

```python
"""Simple solar-array power model (no atmosphere: flux depends only on distance)."""
import numpy as np

SOLAR_CONSTANT_W_M2 = 1361.0
AU_KM = 149_597_870.7
PANEL_MODES = ("vertical-tracking", "horizontal", "fixed-vertical")


def panel_power_w(sun_el, sun_az, sun_dist_km, sun_frac, mode: str = "vertical-tracking",
                  area_m2: float = 1.0, efficiency: float = 0.3, panel_az: float = 0.0):
    el = np.radians(np.asarray(sun_el, float))
    if mode == "vertical-tracking":
        cos_i = np.cos(el)
    elif mode == "horizontal":
        cos_i = np.sin(el)
    elif mode == "fixed-vertical":
        cos_i = np.cos(el) * np.cos(np.radians(np.asarray(sun_az, float) - panel_az))
    else:
        raise ValueError(f"unknown panel mode {mode!r}; expected one of {PANEL_MODES}")
    flux = SOLAR_CONSTANT_W_M2 * (AU_KM / np.asarray(sun_dist_km, float)) ** 2
    return flux * np.clip(cos_i, 0.0, None) * np.asarray(sun_frac, float) * area_m2 * efficiency
```

```python
"""Is the Moon above the 10-degree mask at each Deep Space Network complex?"""
import numpy as np
from skyfield.api import wgs84

from app.ephemeris import kernels, times_from_ms

DSN_STATIONS: dict[str, tuple[float, float, float]] = {
    "goldstone": (35.4267, -116.8900, 1000.0),
    "madrid": (40.4314, -4.2481, 830.0),
    "canberra": (-35.4014, 148.9817, 690.0),
}
MIN_ELEVATION_DEG = 10.0


def moon_elevations(t_ms) -> dict[str, np.ndarray]:
    _, eph, _, _ = kernels()
    t = times_from_ms(t_ms)
    out = {}
    for name, (lat, lon, elev) in DSN_STATIONS.items():
        station = eph["earth"] + wgs84.latlon(lat, lon, elevation_m=elev)
        alt, _, _ = station.at(t).observe(eph["moon"]).apparent().altaz()
        out[name] = np.atleast_1d(alt.degrees)
    return out


def dsn_visible(t_ms, min_el: float = MIN_ELEVATION_DEG) -> dict[str, np.ndarray]:
    return {name: el >= min_el for name, el in moon_elevations(t_ms).items()}
```

```python
"""Combine ephemeris, terrain, DSN and power into one scenario result."""
import json
from datetime import datetime, timezone
from functools import lru_cache
from typing import Literal

import numpy as np
from pydantic import BaseModel, Field, model_validator

from app import dsn, ephemeris, power, terrain, visibility
from app.config import DEM_RUNTIME, HORIZONS_DIR
from app.sites import load_sites

MAX_SAMPLES = 20_000
CURATED_OBS_H = 2.0


def _utc_ms(dt: datetime) -> int:
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=timezone.utc)
    return int(dt.timestamp() * 1000)


class ScenarioRequest(BaseModel):
    lat: float = Field(ge=-90, le=90)
    lon: float = Field(ge=-180, le=360)
    start: datetime
    end: datetime
    step_min: int = Field(default=10, ge=1, le=240)
    obs_h: float = Field(default=2.0, ge=0, le=100)
    panel_mode: Literal["vertical-tracking", "horizontal", "fixed-vertical"] = "vertical-tracking"
    panel_az: float = 0.0
    area_m2: float = Field(default=1.0, gt=0, le=100)
    efficiency: float = Field(default=0.3, gt=0, le=1)

    @model_validator(mode="after")
    def _check_range(self):
        span = _utc_ms(self.end) - _utc_ms(self.start)
        if span <= 0:
            raise ValueError("end must be after start")
        n = span // (self.step_min * 60_000)
        if n > MAX_SAMPLES:
            raise ValueError(f"{n} samples exceeds {MAX_SAMPLES}; increase step_min or shorten the range")
        return self


@lru_cache(maxsize=1)
def _runtime_dem():
    return terrain.load_dem_npz(DEM_RUNTIME) if DEM_RUNTIME.exists() else None


@lru_cache(maxsize=256)
def get_horizon(lat: float, lon: float, obs_h: float):
    if obs_h == CURATED_OBS_H:
        for s in load_sites():
            path = HORIZONS_DIR / f"{s['id']}.json"
            if abs(s["lat"] - lat) < 1e-6 and abs(s["lon"] - lon) < 1e-6 and path.exists():
                d = json.loads(path.read_text())
                return np.array(d["el"]), "LOLA 80 m (precomputed)", d["partial"], d["site_height_m"]
    dem = _runtime_dem()
    if dem is not None and lat <= -80.0:
        h0 = terrain.height_at(dem, lat, lon)
        if not np.isnan(h0):
            mask = terrain.horizon_mask(dem, lat, lon, obs_h)
            return mask, "LOLA 240 m", lat > terrain.FULL_COVERAGE_LAT, round(h0, 1)
    return terrain.smooth_horizon(obs_h), "smooth sphere (no terrain data)", False, None


def compute_scenario(req: ScenarioRequest) -> dict:
    return _compute(req.model_dump_json())


def _r(a, nd=3):
    return np.round(np.asarray(a, float), nd).tolist()


@lru_cache(maxsize=64)
def _compute(key: str) -> dict:
    req = ScenarioRequest.model_validate_json(key)
    step_ms = req.step_min * 60_000
    t = np.arange(_utc_ms(req.start), _utc_ms(req.end), step_ms, dtype=np.int64)
    mask, source, partial, h0 = get_horizon(req.lat, req.lon, req.obs_h)
    e = ephemeris.body_altaz(req.lat, req.lon, (h0 or 0.0) + req.obs_h, t)

    sun_frac = visibility.disk_fraction(
        e.sun_el, visibility.angular_radius_deg(visibility.SUN_RADIUS_KM, e.sun_dist_km),
        visibility.interp_mask(mask, e.sun_az))
    earth_frac = visibility.disk_fraction(
        e.earth_el, visibility.angular_radius_deg(visibility.EARTH_RADIUS_KM, e.earth_dist_km),
        visibility.interp_mask(mask, e.earth_az))
    earth_vis = earth_frac >= 0.5
    stations = dsn.dsn_visible(t)
    dte = earth_vis & np.logical_or.reduce(list(stations.values()))
    pw = power.panel_power_w(e.sun_el, e.sun_az, e.sun_dist_km, sun_frac, req.panel_mode,
                             req.area_m2, req.efficiency, req.panel_az)
    sun_up = sun_frac > 0
    dt_h = req.step_min / 60.0

    return {
        "terrain_source": source,
        "terrain_partial": bool(partial),
        "site_height_m": h0,
        "horizon": {"az": _r(np.arange(len(mask)) * 360.0 / len(mask), 2), "el": _r(mask)},
        "samples": {
            "t": t.tolist(),
            "sun_az": _r(e.sun_az), "sun_el": _r(e.sun_el), "sun_frac": _r(sun_frac),
            "earth_az": _r(e.earth_az), "earth_el": _r(e.earth_el), "earth_frac": _r(earth_frac),
            "earth_vis": earth_vis.tolist(),
            **{f"dsn_{k}": v.tolist() for k, v in stations.items()},
            "dte": dte.tolist(),
            "power_w": _r(pw, 1),
            "sun_vec": _r(e.sun_vec, 5), "earth_vec": _r(e.earth_vec, 5),
        },
        "windows": {
            "sun": visibility.to_windows(t, sun_up, step_ms),
            "earth": visibility.to_windows(t, earth_vis, step_ms),
            "dte": visibility.to_windows(t, dte, step_ms),
        },
        "metrics": {
            "illumination_pct": round(float(sun_frac.mean() * 100), 2),
            "sun_time_pct": round(float(sun_up.mean() * 100), 2),
            "longest_dark_h": round(visibility.longest_run(~sun_up) * dt_h, 2),
            "earth_vis_pct": round(float(earth_vis.mean() * 100), 2),
            "dte_pct": round(float(dte.mean() * 100), 2),
            "mean_power_w": round(float(pw.mean()), 1),
            "energy_wh": round(float(pw.sum() * dt_h), 0),
            "max_sun_el": round(float(e.sun_el.max()), 3),
            "min_sun_el": round(float(e.sun_el.min()), 3),
        },
    }
```

```ts
// frontend/src/lib/time.ts
import type { Win } from '../types';

export const HOUR_MS = 3_600_000;
export const DAY_MS = 86_400_000;

export function indexAt(t: number[], time: number): number {
  if (t.length === 0) return 0;
  let lo = 0;
  let hi = t.length - 1;
  if (time <= t[lo]) return lo;
  if (time >= t[hi]) return hi;
  while (hi - lo > 1) {
    const mid = (lo + hi) >> 1;
    if (t[mid] <= time) lo = mid;
    else hi = mid;
  }
  return time - t[lo] <= t[hi] - time ? lo : hi;
}

export function windowStatus(windows: Win[], time: number, rangeEnd: number) {
  for (const [s, e] of windows) {
    if (time >= s && time < e) return { inWindow: true, msUntilChange: e - time, openEnded: e >= rangeEnd };
    if (s > time) return { inWindow: false, msUntilChange: s - time, openEnded: false };
  }
  return { inWindow: false, msUntilChange: null, openEnded: true };
}

const pad = (n: number) => String(n).padStart(2, '0');

export function formatDuration(ms: number | null): string {
  if (ms === null) return '—';
  if (ms < 60_000) return '<1m';
  const d = Math.floor(ms / DAY_MS);
  const h = Math.floor((ms % DAY_MS) / HOUR_MS);
  const m = Math.floor((ms % HOUR_MS) / 60_000);
  if (d > 0) return `${d}d ${pad(h)}h`;
  if (h > 0) return `${h}h ${pad(m)}m`;
  return `${m}m`;
}

export function addDaysIso(iso: string, days: number): string {
  return new Date(Date.parse(iso) + days * DAY_MS).toISOString().replace('.000Z', 'Z');
}
```

```ts
export const R_MOON_M = 1_737_400;
const rad = (d: number) => (d * Math.PI) / 180;
const deg = (r: number) => (r * 180) / Math.PI;

export function latLonToXY(lat: number, lon: number): [number, number] {
  const r = 2 * R_MOON_M * Math.tan(rad(90 + lat) / 2);
  return [r * Math.sin(rad(lon)), r * Math.cos(rad(lon))];
}

export function xyToLatLon(x: number, y: number): [number, number] {
  const r = Math.hypot(x, y);
  return [-90 + deg(2 * Math.atan((0.5 * r) / R_MOON_M)), deg(Math.atan2(x, y))];
}

/** Moon mean-Earth frame vector -> scene frame (x = projected X, y = projected Y, z = up at south pole). */
export function toScene(v: number[]): [number, number, number] {
  return [v[1], v[0], -v[2]];
}
```

```ts
import type { PanelMode, ScenarioResult, Site } from './types';

export const SYNODIC_DAYS = 29.53;
export const MAX_SCENARIOS = 4;
export const DEFAULT_START = '2026-12-01T00:00:00Z';
const COLORS = ['#c77dff', '#2ec4b6', '#ff6b6b', '#e9ecef'];

export type Scenario = {
  id: string; label: string; siteId: string | null; lat: number; lon: number;
  start: string; days: number; color: string; loading: boolean; error?: string; result?: ScenarioResult;
};
export type NewScenario = Pick<Scenario, 'label' | 'siteId' | 'lat' | 'lon' | 'start' | 'days'>;

type State = {
  sites: Site[]; scenarios: Scenario[]; activeId: string | null; offsetMs: number;
  playing: boolean; speedHoursPerSec: number; explain: boolean; panelMode: PanelMode; exaggeration: number;
  loadSites: () => Promise<void>;
  addScenario: (s: NewScenario) => void;
  duplicateShifted: (id: string, days: number) => void;
  removeScenario: (id: string) => void;
  setActive: (id: string) => void;
  setOffset: (ms: number) => void;
  setPlaying: (p: boolean) => void;
  setSpeed: (h: number) => void;
  toggleExplain: () => void;
  setPanelMode: (m: PanelMode) => void;
  setExaggeration: (x: number) => void;
  runScenario: (id: string) => Promise<void>;
};

let counter = 0;

export const useStore = create<State>((set, get) => {
  const patch = (id: string, p: Partial<Scenario>) =>
    set((st) => ({ scenarios: st.scenarios.map((x) => (x.id === id ? { ...x, ...p } : x)) }));

  return {
    sites: [], scenarios: [], activeId: null, offsetMs: 0, playing: false,
    speedHoursPerSec: 6, explain: false, panelMode: 'vertical-tracking', exaggeration: 1,

    loadSites: async () => set({ sites: await fetchSites() }),

    addScenario: (s) => {
      if (get().scenarios.length >= MAX_SCENARIOS) return;
      const used = new Set(get().scenarios.map((x) => x.color));
      const color = COLORS.find((c) => !used.has(c)) ?? COLORS[0];
      const id = `sc${++counter}`;
      set((st) => ({ scenarios: [...st.scenarios, { ...s, id, color, loading: true }], activeId: st.activeId ?? id }));
      void get().runScenario(id);
    },

    duplicateShifted: (id, days) => {
      const sc = get().scenarios.find((x) => x.id === id);
      if (!sc) return;
      get().addScenario({
        label: `${sc.label} (+${days} d)`, siteId: sc.siteId, lat: sc.lat, lon: sc.lon,
        start: addDaysIso(sc.start, days), days: sc.days,
      });
    },

    removeScenario: (id) =>
      set((st) => {
        const scenarios = st.scenarios.filter((x) => x.id !== id);
        return { scenarios, activeId: st.activeId === id ? (scenarios[0]?.id ?? null) : st.activeId };
      }),

    setActive: (id) => set({ activeId: id }),
    setOffset: (ms) => set({ offsetMs: Math.max(0, Math.min(ms, maxDurationMs(get()))) }),
    setPlaying: (p) => set({ playing: p }),
    setSpeed: (h) => set({ speedHoursPerSec: h }),
    toggleExplain: () => set((st) => ({ explain: !st.explain })),
    setPanelMode: (m) => {
      set({ panelMode: m });
      get().scenarios.forEach((s) => void get().runScenario(s.id));
    },
    setExaggeration: (x) => set({ exaggeration: x }),

    runScenario: async (id) => {
      const sc = get().scenarios.find((x) => x.id === id);
      if (!sc) return;
      patch(id, { loading: true, error: undefined });
      try {
        const result = await fetchScenario({
          lat: sc.lat, lon: sc.lon, start: sc.start, end: addDaysIso(sc.start, sc.days),
          step_min: sc.days > 30 ? 20 : 10, obs_h: 2, panel_mode: get().panelMode,
          panel_az: 0, area_m2: 1, efficiency: 0.3,
        });
        patch(id, { result, loading: false });
      } catch (e) {
        patch(id, { loading: false, error: (e as Error).message });
      }
    },
  };
});

export const activeScenario = (s: State) => s.scenarios.find((x) => x.id === s.activeId);
export const maxDurationMs = (s: Pick<State, 'scenarios'>) =>
  Math.max(0, ...s.scenarios.map((x) => x.days * DAY_MS));
```

```ts
import { useEffect, useState } from 'react';

export type TerrainMeta = { extent_m: number; heightmap_n: number; h_min_m: number; h_max_m: number; hillshade_n: number };
export type Terrain = { meta: TerrainMeta; heights: Float32Array }; // metres, row-major, row 0 = +y

let metaP: Promise<TerrainMeta> | null = null;
let terrainP: Promise<Terrain> | null = null;

export function loadTerrainMeta(): Promise<TerrainMeta> {
  return (metaP ??= fetch('/terrain/meta.json').then((r) => r.json()));
}

function loadTerrain(): Promise<Terrain> {
  return (terrainP ??= Promise.all([
    loadTerrainMeta(),
    fetch('/terrain/heightmap.bin').then((r) => r.arrayBuffer()),
  ]).then(([meta, buf]) => {
    const raw = new Uint16Array(buf);
    const span = meta.h_max_m - meta.h_min_m;
    const heights = new Float32Array(raw.length);
    for (let i = 0; i < raw.length; i++) heights[i] = meta.h_min_m + (raw[i] / 65535) * span;
    return { meta, heights };
  }));
}

export function useTerrain(): Terrain | null {
  const [t, setT] = useState<Terrain | null>(null);
  useEffect(() => { void loadTerrain().then(setT); }, []);
  return t;
}

/** Nearest-neighbour height (m) at projected coordinates, or NaN outside the box. */
export function heightAtXY(t: Terrain, x: number, y: number): number {
  const { extent_m: E, heightmap_n: n } = t.meta;
  const ix = Math.round(((x + E / 2) / E) * (n - 1));
  const iy = Math.round(((E / 2 - y) / E) * (n - 1));
  if (ix < 0 || iy < 0 || ix >= n || iy >= n) return NaN;
  return t.heights[iy * n + ix];
}
```

```tsx
import { useEffect, useState, type MouseEvent } from 'react';
import { latLonToXY, xyToLatLon } from '../lib/projection';
import { loadTerrainMeta, type TerrainMeta } from '../lib/terrain';
import { useStore } from '../store';

type Props = { onPick: (lat: number, lon: number) => void; picked: [number, number] | null };

export function SouthPoleMap({ onPick, picked }: Props) {
  const sites = useStore((s) => s.sites);
  const [meta, setMeta] = useState<TerrainMeta | null>(null);
  useEffect(() => { void loadTerrainMeta().then(setMeta); }, []);
  if (!meta) return null;
  const E = meta.extent_m;
  const toUV = (lat: number, lon: number) => {
    const [x, y] = latLonToXY(lat, lon);
    return [(x + E / 2) / E, (E / 2 - y) / E];
  };
  const click = (e: MouseEvent<HTMLDivElement>) => {
    const r = e.currentTarget.getBoundingClientRect();
    const u = (e.clientX - r.left) / r.width;
    const v = (e.clientY - r.top) / r.height;
    const [lat, lon] = xyToLatLon(u * E - E / 2, E / 2 - v * E);
    onPick(Number(lat.toFixed(4)), Number(lon.toFixed(3)));
  };
  return (
    <div className="map" onClick={click} title="Click to pick custom coordinates (LOLA terrain)">
      <img src="/terrain/hillshade.png" alt="LOLA shaded relief of the lunar south pole" />
      <svg viewBox="0 0 1 1" preserveAspectRatio="none">
        {sites.filter((s) => s.lat <= -80).map((s) => {
          const [u, v] = toUV(s.lat, s.lon);
          return <circle key={s.id} cx={u} cy={v} r={0.008} fill="var(--sun)" stroke="#000" strokeWidth={0.002}><title>{s.name}</title></circle>;
```

```tsx
  const groupH = LANES.length * (ROW + GAP) + GROUP_GAP;
  const H = TOP + scenarios.length * groupH;
  const days = maxMs / DAY_MS;
  const tick = days <= 15 ? 1 : days <= 31 ? 2 : 5;
  const ticks = Array.from({ length: Math.floor(days / tick) + 1 }, (_, k) => k * tick);

  const click = (e: MouseEvent<SVGSVGElement>) => {
    const r = e.currentTarget.getBoundingClientRect();
    const vx = ((e.clientX - r.left) / r.width) * W;
    if (vx >= LABEL) setOffset(((vx - LABEL) / (W - LABEL)) * maxMs);
  };

  return (
    <section className="panel">
      <h2>Timeline · mission elapsed time from each scenario’s start</h2>
      <svg viewBox={`0 0 ${W} ${H}`} width="100%" onClick={click} style={{ cursor: 'pointer' }}>
        {ticks.map((d) => (
          <g key={d}><line x1={x(d * DAY_MS)} x2={x(d * DAY_MS)} y1={TOP - 4} y2={H} stroke="#141c27" />
            <text x={x(d * DAY_MS)} y={11} textAnchor="middle">{d}d</text></g>
        ))}
        {scenarios.map((s, gi) => {
          const t0 = s.result!.samples.t[0];
          return LANES.map((lane, li) => {
            const yy = TOP + gi * groupH + li * (ROW + GAP);
            const wins: Win[] = s.result!.windows[lane.key];
            return (
              <g key={`${s.id}-${lane.key}`}>
                <text x={4} y={yy + ROW - 2} style={{ fill: li === 0 ? s.color : undefined }}>
                  {li === 0 ? `${s.label.slice(0, 18)} · ${lane.label}` : lane.label}
                </text>
                <rect x={LABEL} y={yy} width={x(s.days * DAY_MS) - LABEL} height={ROW} fill="#0a0e14" />
                {wins.map(([a, b], k) => (
                  <rect key={k} x={x(a - t0)} y={yy} width={Math.max(0.5, x(b - t0) - x(a - t0))} height={ROW} fill={lane.color} opacity={0.85} />
                ))}
              </g>
            );
          });
        })}
        <line x1={x(offsetMs)} x2={x(offsetMs)} y1={TOP - 6} y2={H} stroke="#fff" strokeWidth={1.5} />
      </svg>
    </section>
  );
}
```

```tsx
import { formatDuration, HOUR_MS } from '../lib/time';
import { activeScenario, maxDurationMs, useStore } from '../store';

const SPEEDS = [1, 6, 24, 72];

export function TimeScrubber() {
  const { offsetMs, setOffset, playing, setPlaying, speedHoursPerSec, setSpeed } = useStore();
  const maxMs = useStore(maxDurationMs);
  const sc = useStore(activeScenario);

  useEffect(() => {
    if (!playing) return;
    let last = performance.now();
    let raf = 0;
    const loop = (now: number) => {
      const st = useStore.getState();
      const next = st.offsetMs + ((now - last) / 1000) * st.speedHoursPerSec * HOUR_MS;
      last = now;
      if (next >= maxDurationMs(st)) { st.setOffset(maxDurationMs(st)); st.setPlaying(false); return; }
      st.setOffset(next);
      raf = requestAnimationFrame(loop);
    };
    raf = requestAnimationFrame(loop);
    return () => cancelAnimationFrame(raf);
  }, [playing]);

  const utc = sc?.result ? new Date(sc.result.samples.t[0] + offsetMs).toISOString().slice(0, 16).replace('T', ' ') + ' UTC' : '';
  return (
```

```tsx
import { OrbitControls, Stars } from '@react-three/drei';
import { Canvas } from '@react-three/fiber';
import { useMemo } from 'react';
import * as THREE from 'three';
import { latLonToXY, R_MOON_M, toScene } from '../lib/projection';
import { heightAtXY, useTerrain, type Terrain } from '../lib/terrain';
import { indexAt } from '../lib/time';
import { activeScenario, useStore } from '../store';

const R_KM = R_MOON_M / 1000;
const zAt = (xKm: number, yKm: number, hM: number, ex: number) => (hM / 1000) * ex - (xKm * xKm + yKm * yKm) / (2 * R_KM);

function TerrainMesh({ terrain, ex }: { terrain: Terrain; ex: number }) {
  const geom = useMemo(() => {
    const { extent_m, heightmap_n: n } = terrain.meta;
    const E = extent_m / 1000;
    const g = new THREE.PlaneGeometry(E, E, n - 1, n - 1);
    const pos = g.attributes.position;
    for (let k = 0; k < pos.count; k++) pos.setZ(k, zAt(pos.getX(k), pos.getY(k), terrain.heights[k], ex));
    g.computeVertexNormals();
    return g;
  }, [terrain, ex]);
  return (
    <mesh geometry={geom} castShadow receiveShadow>
      <meshStandardMaterial color="#9a9ca0" roughness={1} metalness={0} />
    </mesh>
  );
}

function Scene({ terrain }: { terrain: Terrain }) {
  const sc = useStore(activeScenario);
  const scenarios = useStore((s) => s.scenarios);
  const offsetMs = useStore((s) => s.offsetMs);
  const ex = useStore((s) => s.exaggeration);
  const E = terrain.meta.extent_m / 1000;

  const sitePos = (lat: number, lon: number): [number, number, number] | null => {
    const [x, y] = latLonToXY(lat, lon);
    const h = heightAtXY(terrain, x, y);
    if (Number.isNaN(h)) return null;
    return [x / 1000, y / 1000, zAt(x / 1000, y / 1000, h, ex)];
  };
  const active = sc ? sitePos(sc.lat, sc.lon) : null;
  const target: [number, number, number] = active ?? [0, 0, 0];

  let sun: [number, number, number] = [0, 0, 1];
  let earth: [number, number, number] | null = null;
  if (sc?.result) {
    const i = indexAt(sc.result.samples.t, sc.result.samples.t[0] + offsetMs);
    sun = toScene(sc.result.samples.sun_vec[i]);
    earth = toScene(sc.result.samples.earth_vec[i]);
  }
  const at = (d: [number, number, number], dist: number): [number, number, number] =>
    [target[0] + d[0] * dist, target[1] + d[1] * dist, target[2] + d[2] * dist];

  return (
    <>
      <color attach="background" args={['#000']} />
      <Stars radius={3000} depth={200} count={4000} factor={6} fade />
      <ambientLight intensity={0.03} />
      <directionalLight castShadow position={[sun[0] * 800, sun[1] * 800, sun[2] * 800]} intensity={3}
        shadow-mapSize={[4096, 4096]} shadow-camera-left={-E / 2} shadow-camera-right={E / 2}
        shadow-camera-top={E / 2} shadow-camera-bottom={-E / 2} shadow-camera-near={1} shadow-camera-far={2000} shadow-bias={-0.0004} />
      <TerrainMesh terrain={terrain} ex={ex} />
      {scenarios.map((s) => {
        const p = sitePos(s.lat, s.lon);
        return p && (
          <mesh key={s.id} position={[p[0], p[1], p[2] + 1.5]}>
            <sphereGeometry args={[s.id === sc?.id ? 1.6 : 1, 16, 16]} />
            <meshBasicMaterial color={s.color} />
          </mesh>
        );
      })}
      <mesh position={at(sun, 250)}><sphereGeometry args={[5, 24, 24]} /><meshBasicMaterial color="#f5a524" /></mesh>
      {earth && <mesh position={at(earth, 250)}><sphereGeometry args={[8, 24, 24]} /><meshBasicMaterial color="#4cc9f0" /></mesh>}
      <OrbitControls target={target} maxDistance={1500} />
    </>
  );
}

export function Terrain3D() {
  const terrain = useTerrain();
  const sc = useStore(activeScenario);
  const ex = useStore((s) => s.exaggeration);
  const setEx = useStore((s) => s.setExaggeration);
  const outside = sc ? sc.lat > -84.5 : false;
  return (
    <section className="panel">
      <h2>3D south pole · LOLA terrain lit by the real Sun</h2>
      <div className="three-wrap">
        {terrain ? (
          <Canvas shadows camera={{ position: [0, -220, 140], up: [0, 0, 1], fov: 45, near: 0.5, far: 6000 }}>
            <Scene terrain={terrain} />
          </Canvas>
        ) : <p className="muted" style={{ padding: 12 }}>Loading terrain…</p>}
        <div className="overlay">
          <label className="muted">Vertical exaggeration{' '}
            <input type="range" min={1} max={5} step={0.5} value={ex} onChange={(e) => setEx(Number(e.target.value))} />
          </label>
          <span className="mono">{ex}×</span>
          {outside && <span className="muted">· the active site is outside the ±180 km polar model; showing the pole for context</span>}
        </div>
      </div>
    </section>
  );
}
```
